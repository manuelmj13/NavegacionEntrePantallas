Navegación Entre Pantallas - Jetpack Compose
Este es un proyecto básico de Android para practicar la navegación entre diferentes pantallas usando Jetpack Compose. La aplicación simula una interfaz de exploración con un estilo sencillo y funcional.

¿De qué trata la aplicación?
La app tiene un flujo de 3 pantallas principales:

Inicio: Una bienvenida con un botón para empezar.

Detalle: Una sección donde se muestran un par de tarjetas con información y botones para avanzar al perfil o regresar.

Perfil: Un resumen del usuario con la opción de cerrar sesión y volver al inicio de todo.

Requisitos cumplidos
Implementación de NavHost y NavController.

Al menos 3 pantallas conectadas entre sí.

Uso de componentes interactivos (Botones, Iconos, Cards).

Estructura basada en Material Design 3.

Cómo correr el proyecto
Clonar este repositorio.

Abrirlo en Android Studio.

Dejar que Gradle descargue las dependencias (especialmente la de navigation-compose y material-icons-extended).

Ejecutar en un emulador o teléfono físico.
